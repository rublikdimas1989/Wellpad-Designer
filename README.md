# Wellpad Designer v93d

Проектировщик кустовой площадки (2D, Tkinter) — выпуск **v93d**.

После «Рассчитать» → «Оптимизировать» на дефолтном проекте скважины 9+10
и врезка садятся в **один** коридор 0,30 м с **одним** рядом общих плит.

## Требования

- Python 3.10+ со стандартной библиотекой **Tkinter**
- Windows (рекомендуется) или любая ОС с Python + Tk

## Запуск

**Windows:** дважды нажмите `START_APP.bat`

**Или из терминала** (из корня репозитория):

```bash
python main.py
```

На Windows при необходимости:

```bat
py -3 main.py
```

## Проекты

Сохранённые проекты лежат в папке `Проекты/`. Перед обновлением версии сохраните эту папку.

Исходники приложения (`main.py`, `routing.py`, `startup_ui.py` и модули расчёта/отрисовки), `START_APP.bat`, подробный `README.txt`.
